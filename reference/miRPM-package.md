# miRPM: miRNA RPM Normalization

Functions for the analysis of count matrices and RPM normalization in
miRNA studies.

## Details

This package provides lightweight tools to explore, normalize, and
analyze miRNA-seq count matrices using reads per million (RPM)
normalization.
